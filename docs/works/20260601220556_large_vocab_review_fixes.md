# 대용량 단어장 로딩 리뷰 수정 작업

## 배경

- 대용량 단어장 로딩 변경 리뷰에서 무한 스크롤, 더보기 상태, 로컬 단어 동기화, 오늘 추천 후보 로딩 회귀가 확인되었다.
- 전체 단어를 메모리에 올리지 않는 기존 방향은 유지하고, 필요한 페이지를 DB에서 추가 조회하는 방식으로 보강한다.

## 변경 내용

- 단어 목록 `ListView`에 기존 `ScrollController`를 연결해 50개 이후 페이지가 로드되도록 수정한다.
- 검색/필터 재조회와 더보기 요청이 겹쳐도 `_isLoadingMore`가 고착되지 않도록 상태 해제 조건을 정리한다.
- Supabase 단어 전체 다운로드가 성공한 뒤 다운로드된 ID에 포함되지 않는 로컬 단어를 삭제하는 stale row 정리 API를 추가한다.
- 오늘 추천 후보는 첫 페이지로 목표 추천 수를 채우지 못하면 JLPT 버킷별 다음 페이지를 추가 조회하도록 변경한다.

## 검증 계획

- `flutter test`로 전체 테스트를 실행한다.
- DB 단위 테스트로 stale 단어 삭제와 빈 ID 세트 no-op을 확인한다.
- 추천 서비스 테스트로 첫 후보 페이지가 모두 마스터된 경우 다음 페이지에서 미학습 단어를 가져오는지 확인한다.
